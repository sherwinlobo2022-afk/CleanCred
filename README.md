## What it does

CleanCred is a citizen-driven cleanliness platform that turns real-world
cleanliness actions into measurable civic impact.

Citizens can:

- Play EcoSort to learn waste segregation
- Capture cleanliness issues
- Submit locations for civic attention
- Earn CleanCred credits
- Participate in plantation campaigns
- View national and state leaderboards
- Redeem available rewards
- Support cleanliness initiatives through donations

## Problem

India generates large amounts of waste, while citizens often lack a simple,
engaging and transparent way to participate in local cleanliness efforts.

CleanCred aims to bridge that gap by combining civic participation,
gamification and community-driven reporting.

## Solution

CleanCred provides a unified platform where citizens can participate in
cleanliness activities, earn credits and track their contribution.

## Key Features

### EcoSort
An interactive waste-segregation game teaching users how to correctly
separate different types of waste.

### Impact Capture
Allows citizens to capture cleanliness-related situations and submit
relevant location information.

### Leaderboard
Displays citizen participation through national and state-level rankings.

### Plant Campaign
Encourages users to participate in tree-planting and environmental
activities.

### Rewards
Allows users to use earned credits for available rewards.

### Profile
Users can track their CleanCred activity and contribution.

## How to Run

1. Clone the repository.

2. Open the CleanCred submission folder:

   submissions/cleancred/

3. Open `index.html` in a modern browser.

For the best experience, run the project through a local development server.
